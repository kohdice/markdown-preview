```zig
const std = @import("std");

pub fn main() void {
    std.debug.print("こんにちは、{s}！\n", .{"Markdownプレビュー"});

    for (numbers) |num| {
        std.debug.print("数値: {}\n", .{num});
    }
}
```

```python
# Pythonコードの例
def fibonacci(n):
    """フィボナッチ数列を生成"""
    if n <= 0:
        return []
    elif n == 1:
        return [0]
    elif n == 2:
        return [0, 1]

    fib = [0, 1]
    for i in range(2, n):
        fib.append(fib[-1] + fib[-2])
    return fib

print(fibonacci(10))
```

## スクロールテスト用の長いコンテンツ

これはサンプルテキストです。アプリケーションのパフォーマンスをテストするために使用されます。長いドキュメントでのスクロール機能や表示機能を確認するためのものです。

ユーザーインターフェースの応答性とレンダリング速度を評価するために、様々な種類のマークダウン要素を組み合わせたコンテンツを提供しています。

### セクション 1: アーキテクチャ概要

アプリケーションはZigを使用して構築され、以下のモジュールで構成されています：

- **main.zig**: エントリーポイント、引数処理とプロセスのセットアップ
- **lib.zig**: 公開API面とモジュールの再エクスポート
- **cli.zig**: コマンドラインインターフェースロジックとファイルディスパッチ
- **document.zig**: ファイル読み込みとテキスト前処理
- **render.zig**: Markdown解析とANSIレンダリングエンジン
- **ansi.zig**: ANSIエスケープシーケンス生成（太字、暗色、下線、トゥルーカラー）
- **theme.zig**: カラーテーマ定義（Solarized Darkパレット）

### セクション 2: 設計方針

1. **外部依存ゼロ**: 標準ライブラリのみを使用した純粋なZig実装
2. **行単位レンダリング**: ファイルをメモリに読み込んだ後、行単位で処理
3. **TTY検出**: 出力先に基づいたANSIカラーの自動検出
4. **NO_COLOR準拠**: NO_COLOR環境変数の規約に準拠

### セクション 3: 機能

#### コア機能

- 高速なMarkdown解析とANSIスタイル付きレンダリング
- Solarized Darkカラーテーマによるトゥルーカラー（24ビット）出力
- 見出し、リスト、引用、コードブロックの認識
- インラインコードとリンクのハイライト
- 水平線のレンダリング

#### レンダリングパイプライン

- ファイルをメモリに読み込み
- ブロックレベルの検出を伴う行単位処理
- コードスパンとリンクへのインラインスタイリング適用
- TTYへの出力時にANSIエスケープシーケンスを出力
- パイプ出力やNO_COLOR設定時はプレーンテキストにフォールバック

### セクション 4: 使用例

```bash
# 基本的な使用法
mp README.md

# 任意のMarkdownファイルをプレビュー
mp CONTRIBUTING.md

# パイプ出力（ANSIカラーは自動的に無効化）
mp README.md | less

# 明示的にカラーを無効化
NO_COLOR=1 mp README.md
```
